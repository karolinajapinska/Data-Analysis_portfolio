# E-commerce_accountdynamic-analysis
Basic analysis of emails sent per Country 
This project uses BigQuery SQL to analyze account creation and email engagement across countries, including messages sent, opened, and clicked. CTEs, `UNION ALL`, and window functions are used to calculate country totals and rankings, while a Looker Studio dashboard presents key metrics and email activity over time.
